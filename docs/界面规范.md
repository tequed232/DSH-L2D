# 界面规范

目标：用户能看到的界面保持「清爽，又不失专业感」。这里只管菜单、面板、按钮、气泡、设置页、提示和过渡，不管 Live2D 模型怎么动。

令牌只有一份：`packages/dsh-l2d-plugin/assets/ui-tokens.css`。

悬浮层必须能单独带走这份文件，所以它放在插件的 `assets/` 里，不另做一套。

## 谁在用

| 表面 | 怎么接上 |
|---|---|
| 舞台页 `apps/stage-web` | `main.ts` 直接引入这份样式表 |
| 悬浮层 `lib/overlay.js` | 注入时按自己的脚本地址同步读取 `ui-tokens.css` |
| 调试台、overlay 测试页 | `<link rel="stylesheet" href="/ui-tokens.css">` |
| 渲染自检 `assets/test.html` | `<link rel="stylesheet" href="/dsh-l2d/ui-tokens.css">` |

插件和调试服各自加了一条只读路由，把这份文件原样发出去。没有构建步骤。

## 怎么用

新界面只写 `var(--dsh-…)`，不要再写死颜色、字号、圆角、阴影和过渡时长。

- **颜色**：中性灰做底，只有一个强调色（钢蓝）。涨跌、成功、警告、危险是语义色，不是第二个品牌色。正文和强调色都按 WCAG AA 核对过对比度。
- **字号**：12 / 13 / 14 / 16 / 20 / 26。对应 `--dsh-text-xs` 到 `--dsh-text-2xl`，标签用 `--dsh-text-label`。
- **间距**：4 的倍数。`--dsh-space-1` 是 4px，之后是 8、12、16、24、32、40、48。
- **圆角**：4 / 8 / 12 / 16，再加上全圆 `--dsh-radius-full`（只用在状态胶囊和齿轮这种小圆钮上）。按钮、输入框、菜单用 8 或 12，不再用大圆角胶囊。
- **阴影**：`--dsh-shadow-1` 轻抬、`--dsh-shadow-2` 气泡和菜单、`--dsh-shadow-3` 设置面板和底部抽屉。
- **动效**：一条缓动 `--dsh-ease`（缓出，不回弹）。时长只有 120 / 200 / 320ms。系统打开「减少动态效果」时，这三个时长变成 0。
- **层级**：舞台里栏 10、遮罩 40、抽屉 50。悬浮层用很大的固定值，只是为了盖住宿主页面，名字是 `--dsh-z-overlay`、`--dsh-z-menu`、`--dsh-z-panel`。

主题靠 `<html data-theme="dark|light">`。悬浮层本身不跟宿主主题走，菜单和设置面板始终用深色令牌，避免把宿主页面的变量冲掉。角色气泡固定浅底深字，盖在任何背景上都读得清。

## 改的时候

1. 只改 `ui-tokens.css`。
2. 组件里如果出现新的魔法数字，先看能不能对上现有档位，对不上再加一档，不要在组件里写死。
3. 占位剪影（没加载模型时的椭圆）的圆角是身体轮廓，不是界面圆角，留在组件里。

## 刻意没动

- 邪神模式那一层（`.l2d-yandere-fx`）的颜色和 0.7s 过渡保持原样。
- 模型动作、拖拽弹簧、参数动画不是界面样式。
- 组件文件仍叫 `M3*`，只是历史名字，视觉已经不再跟 Material 3 走。
